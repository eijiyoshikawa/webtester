# ローンチ前チェックリスト

> 静的HTML→WordPress 移行案件の本番リリース前に必ず確認するべきチェック項目。
> DNS切替前・後の双方で漏れがないよう、フェーズ別に整理。

---

## ⏱ チェックリストの使い方

- 各項目は **チェックボックス [ ]** にチェックを入れて完了確認
- 「**担当**」欄を書き加えて関係者間で進捗共有
- 「**証跡**」欄にスクリーンショット・ログURLを残すと検収時に便利
- ローンチ予定日の **2週間前 / 1週間前 / 当日 / 直後** で進捗レビュー推奨

## Phase 3：パフォーマンス・SEO（1週間前〜数日前）

### 3.1 ページ表示速度
- [ ] PageSpeed Insights：モバイル **70点以上**
- [ ] PageSpeed Insights：PC **80点以上**
- [ ] First Contentful Paint < 2.0秒
- [ ] Largest Contentful Paint < 2.5秒
- [ ] Cumulative Layout Shift < 0.1

### 3.2 キャッシュ・最適化
- [ ] WP Rocket / W3 Total Cache 設定完了
- [ ] HTML/CSS/JS minify
- [ ] 画像 WebP 自動配信
- [ ] Lazy Load 有効
- [ ] CDN 連携（Cloudflare 等）

### 3.3 SEO 基本設定
- [ ] Yoast SEO / All in One SEO 導入・設定
- [ ] 各固定ページに **メタディスクリプション** 設定
- [ ] 各固定ページに **OGP画像** 設定（1200×630px推奨）
- [ ] **XMLサイトマップ** 自動生成（`/sitemap.xml` 等）
- [ ] **robots.txt** 適切設定（ステージング環境はnoindex）
- [ ] 構造化データ（JSON-LD）
  - [ ] Organization
  - [ ] LocalBusiness
  - [ ] Article（ブログ記事）
- [ ] canonical タグ適切設定
- [ ] Google Search Console プロパティ登録（移行先ドメイン）
- [ ] Google Analytics 4（GA4）タグ設置・データ受信確認

### 3.4 リダイレクト設定（旧URLからのSEO継承）
- [ ] 既存サイトのURL一覧棚卸し
- [ ] 変更されるURLを特定
- [ ] **301 リダイレクト**設定（Redirection プラグイン推奨）
- [ ] リダイレクトループ・無限ループ無し確認
- [ ] 主要ページの旧URL→新URL動作確認

### 3.5 アクセシビリティ
- [ ] 画像 alt 属性すべて設定済み
- [ ] 見出しレベル（h1〜h6）順序正しい
- [ ] フォーム label 適切
- [ ] キーボード操作可能
- [ ] カラーコントラスト WCAG AA 準拠
- [ ] ARIA 属性適切（既存HTML準拠）

## Phase 5：DNS切替実施

### 5.1 切替手順
- [ ] DNS Aレコード（または CNAME）を新サーバーへ向ける
- [ ] TTL を一時的に 60〜300秒に短縮（事前作業）
- [ ] 切替実施
- [ ] DNS 反映確認（`dig +short example.com` 等）
- [ ] **複数地点・複数DNS** から確認（[whatsmydns.net](https://whatsmydns.net/)）

### 5.2 SSL証明書
- [ ] 新サーバーでSSL有効
- [ ] HTTPS でアクセス可能
- [ ] 証明書チェーン正常
- [ ] mixed content（混在コンテンツ）無し

### 5.3 切替直後確認（30分以内）
- [ ] トップページ表示
- [ ] お問い合わせフォーム送信テスト
- [ ] 主要ページ表示
- [ ] 画像表示
- [ ] エラーログ確認（`wp-content/debug.log` 等）

## Phase 7：ロールバック計画（万が一）

### 7.1 ロールバック判断基準
- [ ] サイト全体が表示されない
- [ ] お問い合わせフォームが動作しない
- [ ] 主要ページに重大な表示崩れ
- [ ] DBエラーが頻発

### 7.2 手順
1. 関係者へ即時通知
2. DNS A レコードを旧サーバーへ戻す
3. DNS反映を待機（TTL短縮済みなら数分）
4. 旧サイト動作確認
5. 原因調査・修正
6. 再切替計画
