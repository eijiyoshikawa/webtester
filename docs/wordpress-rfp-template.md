## 1. 目的・背景

- 現状は静的 HTML 構成で、テキスト・画像・お知らせ等の更新には HTML 直接編集が必要
- 社内スタッフが管理画面から **コードに触れず** 更新できる体制への移行
- WordPress + ACF Pro で 画像差し替え・PDF差し替え・お知らせ追加・拠点情報編集 を完結
- **デザインは現状サイトを忠実に再現**（リデザインは含まない）

### 関連リソース（受託者へ提供）

- **既存ソースコード：** `eijiyoshikawa/webtester` リポジトリ `corp/anju` ブランチ
- **ACF 設計書：** `docs/wordpress-acf-spec.md`
- **ACF インポートJSON：** `docs/acf-fields.json`
- **運用マニュアル（受領者向け原稿）：** `docs/site-operations-manual.md`
- **画像移行計画：** `docs/image-migration-plan.md`

## 2. 機能要件

### 2.1 ページ構成（既存サイトをそのまま再現）

| ページ | URL（移行後 permalink） | 主要セクション |
|--------|------------------------|----------------|
| トップ | `/` | ヒーロースライダー / philosophy / news / our service / service detail / message / footer |
| 訪問看護 | `/service/houkan/` | hero / 事業概要 / メイン写真 / 料金PDFカード / ギャラリー / contact |
| グループホーム | `/service/grouphome/` | hero / 事業概要 / メイン写真 / ホーム一覧（4拠点）/ ギャラリー / contact |
| お知らせ一覧 | `/news/` | 投稿一覧 |
| お知らせ詳細 | `/news/{slug}/` | 投稿詳細 |
| ブログ一覧 | `/blog/` | 投稿一覧 |
| ブログ詳細 | `/blog/{slug}/` | 投稿詳細 |
| お問い合わせ | `/contact/` | フォーム |
| 完了（thanks） | `/contact/thanks/` | 送信完了表示 |
| プライバシーポリシー | `/privacy-policy/` | 利用規約・個人情報取扱い |
| 運用マニュアル（社内用） | `/manual/` または非公開URL | パスワード保護 |

### 2.2 共通機能

- レスポンシブ対応（PC / タブレット / スマホ）— ブレークポイントは既存 CSS 準拠
- ヘッダー（ロゴ・グローバルナビ・ハンバーガーメニュー）
- フッター（住所・SNS・ナビゲーション）
- お問い合わせフォーム（後述）
- パンくずリスト（任意）
- 404 ページ（既存 `/404.html` を WP テンプレート化）

### 2.3 ACF カスタムフィールド（管理画面）

`docs/acf-fields.json` をインポートすることで以下4グループ・36フィールドを構築：

1. **トップページ設定** — ヒーロー・philosophy・message・サービスロゴ
2. **訪問看護ページ設定** — メイン写真・料金/サービスPDF・ギャラリー
3. **グループホームページ設定** — メイン写真・拠点Repeater・ギャラリー
4. **サイト共通設定（Options Page）** — ロゴ・連絡先・SNS

詳細は `docs/wordpress-acf-spec.md` 参照。

### 2.4 カスタム投稿タイプ

| 投稿タイプ | スラッグ | 内容 |
|------------|----------|------|
| お知らせ | `news` | タイトル・公開日・本文・アイキャッチ・外部リンク（任意） |
| ブログ | `post`（標準）または `blog` | タイトル・公開日・本文・アイキャッチ・カテゴリー |

トップページ「news」セクションには最新3件を自動表示。

### 2.5 お問い合わせフォーム

- **使用プラグイン：** Contact Form 7 + Flamingo（送信履歴保存）
- **項目：** お名前・メール・電話番号（任意）・件名・お問い合わせ内容・個人情報同意チェックボックス
- **送信後：** `/contact/thanks/` へリダイレクト
- **管理者メール：** ACF Options Page の代表メールアドレス宛
- **自動返信メール：** 送信者宛にも自動配信
- **スパム対策：** Google reCAPTCHA v3 + Akismet 併用
- **配信信頼性：** WP Mail SMTP プラグインで Gmail / SendGrid / Amazon SES 等の SMTP 経由送信
- **バリデーション：** 必須項目・メール形式・電話番号形式

### 2.6 運用マニュアルページ

- 固定ページ「運用マニュアル」を作成
- **公開状態：パスワード保護**（パスワードは納品時に共有）
- メニューには非表示（直接URLのみアクセス可）
- 内容：`docs/site-operations-manual.md` を WP 編集画面にコピペ → Markdown→HTML 変換

## 3. 非機能要件

### 3.1 パフォーマンス
- Google PageSpeed Insights：モバイル・PC ともに **70点以上** を目標
- ページロード時間：3秒以内（4G接続時）
- 画像最適化：WebP 自動変換（ShortPixel または EWWW Image Optimizer）
- ページキャッシュ：WP Rocket または W3 Total Cache

### 3.2 セキュリティ
- WordPress / プラグイン / テーマの **自動更新有効化**
- ログイン保護：ログインURL変更（SiteGuard WP Plugin）+ ログイン試行制限
- 二要素認証：管理者アカウントは必須
- ファイル整合性監視：Wordfence または iThemes Security
- HTTPS 必須（Let's Encrypt 等）
- WP 管理画面の IP 制限（要件に応じて）

### 3.3 SEO
- Yoast SEO または All in One SEO 導入
- XML サイトマップ自動生成 → Google Search Console 登録
- 各固定ページにメタディスクリプション・OGP 画像設定欄
- 構造化データ（JSON-LD）：Organization / LocalBusiness / Article
- **既存URLからの 301 リダイレクト**（SEO評価維持のため必須）
- canonical タグ適切設定

### 3.4 アクセシビリティ
- WAI-ARIA 適切なロール・属性付与（既存HTML準拠）
- キーボード操作可能
- 画像 alt 属性：管理画面で編集可
- カラーコントラスト：WCAG AA 準拠

### 3.5 ブラウザ対応
- Chrome / Safari / Edge / Firefox 最新2バージョン
- iOS Safari / Android Chrome 最新

### 3.6 バックアップ
- **UpdraftPlus** または **All-in-One WP Migration** 導入
- 自動バックアップ：DB日次・ファイル週次
- 保存先：Google Drive / Dropbox / Amazon S3（同サーバー外）
- 復元手順を運用マニュアルに記載

## 4. 運用要件

### 4.1 ユーザー権限設計

| ロール | 権限範囲 |
|--------|----------|
| 管理者（Administrator） | 全機能（プラグイン・ユーザー管理含む）。納品先2名以内 |
| 編集者（Editor） | 投稿・固定ページ・ACFフィールド編集。コンテンツ担当スタッフ |
| 投稿者（Author） | ブログ投稿のみ（必要に応じて） |

### 4.2 管理画面ローカライズ
- 日本語管理画面（標準対応）
- 不要メニューは非表示化

### 4.3 教育・引き継ぎ
- 納品時オンライン操作レクチャー：1回（90分程度）
- 録画提供（後日復習用）
- 質問対応：ローンチ後2週間メールサポート

### 4.4 保守契約（オプション）
- 月額定額：WP本体・プラグイン更新・軽微な不具合対応・バックアップ確認
- 別契約として提案歓迎

## 5. ホスティング要件

- **PHP 8.1+ / MySQL 5.7+**
- ディスク容量：10GB 以上推奨
- 月間転送量：100GB 以上
- 推奨サービス：エックスサーバー / ConoHa WING / Kinsta / SiteGround
- サブドメイン or 独自ドメインでステージング環境付帯
- **常時SSL（無料/有料いずれか）**

## 6. 移行作業

### 6.1 画像・ファイル移行
- 既存 `assets/images/` 配下を WP メディアライブラリへ一括インポート
- 既存 `assets/docs/*.pdf` を同様にインポート
- 詳細は `docs/image-migration-plan.md` 参照

### 6.2 既存コンテンツ移行
- 静的HTMLのテキストを各固定ページ/カスタム投稿タイプへ転記
- お知らせ既存記事（あれば）も投稿として登録

### 6.3 リダイレクト設定
- 旧URL→新URLが変わる場合：301 リダイレクト（Redirection プラグイン推奨）
- 既存URL構造（`/service/houkan/` 等）はそのまま維持

### 6.4 DNS切替計画
- ステージング環境で **完全動作確認** 後に DNS 切替
- 切替前後でのアクセス比較（Search Console 監視）
- ロールバック手順を事前に文書化

## 8. 検収条件

- 全ページが本番ドメインで表示される
- 全画像・PDF が表示・ダウンロードできる
- お問い合わせフォーム送受信が成功する（受信メアドへ実際に到達）
- ACF フィールドから画像差し替えが可能
- 管理画面で新規お知らせ投稿が可能
- 既存URLからの301リダイレクトが機能する
- PageSpeed スコア要件を満たす
- ステージング環境が利用可能
- バックアップが自動実行されている
